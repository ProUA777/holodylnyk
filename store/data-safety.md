# Відповіді для Play Console

Підказки для анкет у Play Console. Формулювання полів у консолі можуть дещо відрізнятися. Відповідай за змістом і звіряйся з поточною довідкою Google.

## Безпека даних (Data safety)

| Питання | Відповідь |
|---|---|
| Чи збирає або передає застосунок дані користувачів? | **Так** |
| Чи шифруються дані під час передавання? | **Так** (HTTPS через Caddy) |
| Чи можуть користувачі попросити видалити дані? | Фото не зберігаються. Локальну історію видаляють у застосунку («Очистити історію») |

**Типи даних:**

| Тип | Збирається | Передається третім особам | Обробляється тимчасово | Обов'язково | Мета |
|---|---|---|---|---|---|
| Фото й відео → **Фото** | Так | Ні* | **Так** (ephemeral) | Ні, користувач сам вирішує | Функції застосунку |
| Ідентифікатори пристрою → **Інші ідентифікатори** (випадковий ID застосунку) | Так | Ні | Ні (зберігається до 3 днів для ліміту) | Так | Функції застосунку (запобігання зловживанням) |
| Повідомлення про проблему (текст AI-відповіді) | Так | Ні | Ні | Ні | Функції застосунку |

\* Постачальник AI-аналізу обробляє фото від нашого імені як підрядник (service provider). За визначенням Google це не вважається передаванням третім особам.

Не збираються: ім'я, email, контакти, геолокація, рекламний ID, історія браузера, фінансові дані.

## Цільова аудиторія та вміст

- **Вікові групи:** 6–8, 9–12, 13–15 (і 18+ для батьків). Якщо серед вікових груп є діти, діє програма Google Play Families: без реклами, з політикою конфіденційності, без передавання ідентифікаторів пристрою від дітей.
- **Чи привабливий застосунок для дітей:** Так.
- **Реклама:** Ні.
- **Покупки в застосунку:** Ні.
- **Доступ до застосунку:** без входу в обліковий запис. Для перевірки можна натиснути «Приклади купок» або відкрити каталог.

## Рейтинг вмісту (анкета IARC)

Категорія «Інше / Утиліта / Освіта». Насильства, сексуального вмісту, нецензурної лексики, азартних ігор, наркотиків немає. Користувачі не спілкуються між собою й не діляться вмістом. Застосунок не збирає дані про місцезнаходження.

Очікуваний результат: **3+ / PEGI 3**.

## Вміст, згенерований AI

Застосунок генерує ідеї моделей за допомогою AI. Як вимагає політика Google щодо AI-вмісту:
- кнопка **«Поскаржитися на відповідь»** (прапорець) є на екрані результату та в кожній AI-ідеї;
- скарги надходять на сервер (`POST /v1/report`) і зберігаються в таблиці `reports` (SQLite);
- у системній інструкції AI заборонено небезпечний вміст і торгові марки, а тон має бути дружнім до дітей.

Регулярно переглядай скарги:
```bash
docker compose exec api python -c "import sqlite3;print(sqlite3.connect('/srv/data/limits.db').execute('select * from reports order by ts desc limit 50').fetchall())"
```

## Дозволи

- **Камера** — використовується через системний інтерфейс image_picker, окремий дозвіл CAMERA не оголошено.
- **Фото** — системний Photo Picker, дозвіл на всю галерею не потрібен.
- **Інтернет** — для AI-аналізу.
